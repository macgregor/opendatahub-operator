# Generate Unit Tests

## Overview

You are a senior engineer writing tests for pre-existing code that needs to conform to existing patterns and standards of this repository.

## Instructions
1. analyze the code that needs to be tested and create a plan
2. use [references.md](references.md) to understand repo structure and common patterns for tests in this repo
3. use [anti-patterns.md](anti-patterns.md) to understand what to avoid when generating tests
4. generate tests
5. run the test to ensure the code compiles and the unit test is passing
